# C++ Object-Oriented Programming Practicals

This repository contains nine C++ practical programs demonstrating core object-oriented programming and standard library concepts.

## Practicals

| File | Topic |
|---|---|
| `practical1.cpp` | Constructors for a music record class |
| `practical2.cpp` | Bank account class and static member variables |
| `practical3.cpp` | Employee details using multiple and virtual inheritance |
| `practical4.cpp` | Abstract classes and polymorphism for vehicle rentals |
| `practical5.cpp` | Complex number arithmetic and operator overloading |
| `practical6.cpp` | Binary file handling for student records |
| `practical7.cpp` | Custom exceptions and user input validation |
| `practical8.cpp` | Function templates and sorting |
| `practical9.cpp` | STL vectors and item record operations |

## Requirements

- A C++ compiler that supports C++11 or later
- Windows PowerShell or Command Prompt

## Compile and Run

Compile a single program:

```powershell
g++ practical1.cpp -o practical1.exe
.\practical1.exe
```

Replace `practical1.cpp` and `practical1.exe` with the desired practical file.

Compiled executables are also available in the `output` folder.
